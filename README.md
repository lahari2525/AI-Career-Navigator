# AI Career Navigator

AI Career Navigator is a simple artificial intelligence system that recommends a technology career path based on a user's skills.

## Project Idea

Many students are confused about which career path to choose in technology.  
This project analyzes the skills entered by the user and recommends the most suitable career.

## Example Careers

- AI Engineer
- Cloud Engineer
- Software Developer
- Data Scientist

## How It Works

1. User enters skills in the web interface
2. Flask backend receives the input
3. AI reasoning engine compares the skills with career requirements
4. The best matching career is recommended
